# מצב הפרויקט

## 📌 סטטוס נוכחי
הפרויקט נמצא בשלב 1: פיתוח מקומי (`localhost`), ובפועל הוקם בסיס Backend ראשוני.

יש כרגע:
- שרת `Express` פעיל עם מבנה תיקיות מסודר (`routes` / `controllers` / `services` / `middlewares`)
- חיבור ל-`PostgreSQL` דרך `Prisma`
- סכמת DB ראשונית ומיגרציות
- API בסיסי לישויות של האזור האישי

עדיין אין MVP מלא, אין Auth אמיתי, ואין מימוש של רוב הפיצ'רים המרכזיים מהאפיון.

## ✅ מה כבר בוצע
- הוגדר סטאק השרת: `Node.js`, `Express`, `TypeScript`, `Prisma`, `PostgreSQL`
- נוצרה סכמת Prisma לישויות המרכזיות:
  `User`, `Client`, `ClientProject`, `ContentGroup`, `ContentItem`, `Chat`, `ChatMessage`
- נוצרו מיגרציות ב-`prisma/migrations`
- נוצר לקוח Prisma וחיבור למסד
- הוגדר שרת בסיסי עם `app.ts` ו-`server.ts`
- קיים `health` endpoint
- קיים middleware של `mockAuth` לצורך פיתוח זמני
- קיימת בדיקת הרשאות בסיסית ללקוח/אדריכלית (`requireClientAccess`, `requireArchitect`)
- קיימים endpoints בסיסיים עבור:
  - יצירה ושליפה של לקוח
  - יצירה ושליפה של משתמש
  - יצירת פרויקט לקוח
  - שליפת רשימת פרויקטים ללקוח
  - יצירה ושליפה של `ContentGroup`
  - יצירה ושליפה של `ContentItem`
- קיימת בדיקת Prisma נסיונית (`/test/prisma-test`)

## 🔄 מה בתהליך
- בניית שכבת Backend ראשונית עבור האזור האישי
- מעבר מאפיון תיאורטי למודלים ו-API בסיסי
- התחלה של מנגנון הרשאות, אבל כרגע רק בגרסת `mock`

## ❌ מה עדיין חסר
- Auth אמיתי:
  - התחברות
  - ניהול סיסמאות תקין
  - זיהוי משתמש אמיתי במקום `mockAuth`
- מענה מלא לישויות שכבר קיימות בסכמה:
  - אין endpoints לצ'אט
  - אין endpoints להודעות צ'אט
- פיצ'רים מרכזיים מהאפיון שעדיין לא קיימים:
  - אתר תדמית ציבורי
  - פרויקטים ציבוריים
  - ניהול טקסטים ותמונות לאתר
  - ציר זמן מתוכנן / היסטורי
  - העלאות קבצים אמיתיות
  - סטטוסים, דדליינים והתראות
  - דשבורד אדריכלית
- חסר טיפול מסודר בשגיאות ובוולידציה
- חסרות בדיקות
- חסר endpoint אמיתי לשליפת פרויקט בודד:
  כרגע `getClientProjectById` מחזיר `501 not implemented`
- קיימים פערים בין האפיון לבין המימוש:
  - באפיון מופיע שלקוח יכול להכיל כמה משתמשים, אבל זה עדיין לא מגובה ב-flow מלא
  - באפיון מופיעים timeline ו-public projects, אך הם לא קיימים כרגע בסכמה הפעילה
  - יש חוסר אחידות קטן בשמות שדות בין האפיון למימוש בפועל

## ⏭️ הצעד הבא
הצעד הבא המומלץ הוא לייצב קודם את בסיס האזור האישי לפני שממשיכים לפיצ'רים חדשים.

להתמקד עכשיו ב-3 משימות:
- להשלים את flow של `ClientProject`:
  - לממש `getClientProjectById`
  - להחזיר גם `ContentGroups` ו-`ContentItems` לפי הצורך
- להחליף את `mockAuth` ב-Auth אמיתי או לפחות להכין תשתית Auth מסודרת
- להחליט ולעגן במסד ובקוד את המודל הבא שחסר באפיון הממומש:
  `Timeline` או `Chat`

המלצת עבודה:
- קודם להשלים `ClientProject` ו-Auth
- אחר כך לעבור ל-`Chat`
- רק אחרי זה להרחיב ל-`Timeline` ולחלק הציבורי של האתר

## 🧠 הערות חשובות
- כרגע הקוד הוא בסיס Backend בלבד, לא מערכת מלאה
- האפיון רחב יותר משמעותית ממה שממומש בפועל
- יש לשמור על התאמה שוטפת בין `docs/PROJECT-STATE.md` לבין ההתקדמות האמיתית בקוד
- לפי `AI-GUIDE.md`, התפקיד כאן הוא להכווין את הצעד הבא ולא "לדלג" ישר למימוש גדול
